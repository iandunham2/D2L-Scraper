There has been many different highs and lows with being in this class this semester. I love being creative and learning more things and this class allows for both. I have learned a lot by using a software I have never used before and now that I have worked in it with this class and digital media I am able to put in my resume that I know how to work in DaVinchi Resolve which has been a requirement in different internships and jobs I have applied for. However the process of learning how to do different tools and uploads has been a little Bit of a struggle this semester. I tend to focus too much on the creative part of the different assignment and don't leave myself enough time for the more technical part especially when it is something I had not done before. As the semester goes by I tend to continue with is struggle and need to focus on the technical part of each assignment.
