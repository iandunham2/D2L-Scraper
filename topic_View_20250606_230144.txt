I never thought of podcasting as ever really being an option for me or something that I really want to do. After this class, it is nice to have these skills, though. It was always been a dream of mine to be a content creator, especially on YouTube. I don't really have any idea on what kinda content, probably just like vlogs and golfing content. I think that if I ever end up doing that, then having a podcast as well is something that a lot of these content creators are doing these days, so it is very helpful to learn these skills now so that I can have a sort of jumpstart if that happens. I want to go into sales after college in a more realistic sense, so I'm not sure honestly, how helpful knowing this will be, but I think that if something changes or later in life I want to be a part of a content creation team, then these skills will really come in handy. This class has also just taught me how to talk for 15 plus minutes straight and to try and keep things interesting. I think that is a very useful skill to have in general, especially if I do sales and I have to keep conversations going. So, besides the production aspect of this class, I think that learning how to write a script and plan out my dialogues was very helpful because as a salesman, I'm gonna have to have pitches ready and stuff and know how to improvise/ think on my feet. I think it is cool to know as many things as possible and have a lot of diverse skills because you never know when these new skills can come in handy later in life for something you may end up doing.
